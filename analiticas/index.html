API Analíticas (PowerBI) (1.0)

Download OpenAPI specification:

Esta API permite acceder a la información analítica de talento cloud consumida por PowerBI para la construcción de reportes. Cada módulo de negocio se agrupa bajo su propio tag (ej. Hoja de Vida, Selección); a medida que se documenten nuevos módulos de analíticas se agregarán como tags adicionales dentro de esta misma especificación.

Manejo de errores

Los errores habituales pueden incluir:

- `400 Bad Request`: Parámetros requeridos faltantes o con formato
inválido.

- `401 Unauthorized`: Token JWT inválido, expirado o ausente.

- `403 Forbidden`: El usuario autenticado no tiene permisos suficientes.

- `404 Not Found`: El recurso solicitado no existe.

- `500 Internal Server Error`: Error inesperado en el servidor.


Cuando sea posible, cada endpoint detallará sus códigos de error
específicos y estructura de respuesta en su propia descripción.

## Autenticación

Estos servicios están pensados para ser consumidos por PowerBI y se
protegen con autenticación básica HTTP (usuario y contraseña), las
cuales son provistas por talento cloud para la integración.

HojaDeVida

Datos demográficos y de hoja de vida de los colaboradores (idiomas, estudios formales, conocimientos y reporte demográfico completo).

pbiIdiomas

Retorna el listado de idiomas registrados en la hoja de vida de cada colaborador activo, con su nivel de lenguaje y el promedio general obtenido. Pensado para ser consumido como fuente de datos de PowerBI.

Si no existen registros de idiomas para ningún colaborador, el servicio retorna igualmente un arreglo con un único registro cuyos campos vienen vacíos (comportamiento explícito del backend, no es un error).

Authorizations:
basicAuth

Responses

Servidor de producción

https://clientex.talento.cloud/html/pbi/data/demograficas/idiomas.json

pbiDemograficas

Retorna el reporte demográfico completo de los colaboradores activos con hoja de vida activa: datos básicos de usuario, fechas de ingreso e inicio de cargo, información de residencia, tipo de vivienda, estado civil, género, escolaridad, años para jubilación, años de experiencia general, clasificadores organizacionales (área, negocio, empresa, UEN, vicepresidencia, sede, ciudad, regional) y datos del jefe directo. Pensado para ser consumido como fuente de datos de PowerBI.

A diferencia de los demás endpoints de este módulo, si no hay resultados este servicio retorna un arreglo vacío (no agrega un registro con campos vacíos).

Seleccion

Datos analíticos del módulo de Selección: procesos de requisición, candidatos, etapas, encuestas de satisfacción y maestros de apoyo.

informacionProcesos

Retorna la información detallada de los procesos de requisición de selección: datos generales (fechas, estado, vacantes, salario, duración), clasificadores organizacionales (cargo, área, negocio, empresa, UEN, vicepresidencia, sede), responsables del proceso, idioma/nivel requerido y el tiempo transcurrido calculado según el calendario laboral configurado. Pensado para ser consumido como fuente de datos de PowerBI.

Authorizations:
basicAuth

Retorna el Acuerdo de Nivel de Servicio (ANS, en días) calculado para cada cargo, según la configuración general de origen del ANS (trv_configuracion_general.origen_ans): puede tomarse del propio cargo, del nivel organizacional (tipo de cargo) o de la categoría del cargo. Pensado para ser consumido como fuente de datos de PowerBI.

Si no existen cargos configurados, el servicio retorna igualmente un arreglo con un único registro cuyos campos vienen vacíos (comportamiento explícito del backend, no es un error).
