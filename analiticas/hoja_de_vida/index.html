API Analíticas - Hoja de Vida (PowerBI) (1.0)

Download OpenAPI specification:

Esta API permite acceder a la información demográfica y de hoja de vida de los colaboradores de una empresa, consumida por PowerBI para la construcción de reportes analíticos.

Manejo de errores

Los errores habituales pueden incluir:

- `400 Bad Request`: Parámetros requeridos faltantes o con formato
inválido.

- `401 Unauthorized`: Token JWT inválido, expirado o ausente.

- `403 Forbidden`: El usuario autenticado no tiene permisos suficientes.

- `404 Not Found`: El recurso solicitado no existe.

- `500 Internal Server Error`: Error inesperado en el servidor.


Cuando sea posible, cada endpoint detallará sus códigos de error
específicos y estructura de respuesta en su propia descripción.

## Autenticación

Estos servicios están pensados para ser consumidos por PowerBI y se
protegen con autenticación básica HTTP (usuario y contraseña), las
cuales son provistas por talento cloud para la integración.

Demograficas

pbiIdiomas

Retorna el listado de idiomas registrados en la hoja de vida de cada colaborador activo, con su nivel de lenguaje y el promedio general obtenido. Pensado para ser consumido como fuente de datos de PowerBI.

Si no existen registros de idiomas para ningún colaborador, el servicio retorna igualmente un arreglo con un único registro cuyos campos vienen vacíos (comportamiento explícito del backend, no es un error).

Authorizations:
basicAuth

Responses

Servidor de producción

pbiEstudiosFormales

Retorna el listado de estudios formales registrados en la hoja de vida de cada colaborador activo: título obtenido, año de graduación, estado del estudio, niveles cursados, nivel de escolaridad e institución educativa. Pensado para ser consumido como fuente de datos de PowerBI.

Si no existen registros de estudios formales para ningún colaborador, el servicio retorna igualmente un arreglo con un único registro cuyos campos vienen vacíos (comportamiento explícito del backend, no es un error).

basicAuth

pbiDemograficas

Retorna el reporte demográfico completo de los colaboradores activos con hoja de vida activa: datos básicos de usuario, fechas de ingreso e inicio de cargo, información de residencia, tipo de vivienda, estado civil, género, escolaridad, años para jubilación, años de experiencia general, clasificadores organizacionales (área, negocio, empresa, UEN, vicepresidencia, sede, ciudad, regional) y datos del jefe directo. Pensado para ser consumido como fuente de datos de PowerBI.

A diferencia de los demás endpoints de este módulo, si no hay resultados este servicio retorna un arreglo vacío (no agrega un registro con campos vacíos).

Authorizations:
basicAuth

Responses

Servidor de producción
