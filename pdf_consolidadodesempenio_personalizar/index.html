Download OpenAPI specification:

Contiene endpoints utilizados para personalizar reporte pdf consolidado de desempeño

Manejo de errores

Los errores habituales pueden incluir:

- `400 Bad Request`: Parámetros requeridos faltantes o con formato
inválido.
    
- `401 Unauthorized`: Token JWT inválido, expirado o ausente.
    
- `403 Forbidden`: El usuario autenticado no tiene permisos suficientes.
    
- `404 Not Found`: El recurso solicitado no existe.
    
- `500 Internal Server Error`: Error inesperado en el servidor.
    

Cuando sea posible, cada endpoint detallará sus códigos de error
específicos y estructura de respuesta en su propia descripción.

Editar Elemento PDF

Para personalizar los elementos del pdf, los cuales encuentras en endpoint anterior, tener cuidado especial con CONSOLIDADO_DESEMPENIO_COLORES_TEXTO que recibe un json y no necesita membrete y tambien con CONSOLIDADO_DESEMPENIO_INDV_EXPLICACION que cuando no existe significa que esa hoja no se imprimirá en el pdf

Authorizations:
bearer
path Parameters
codModeloMapaTalento
required
string
Example: 1

Codigo del modelo de mapa de talento

idElemento
required
string
Example: CONSOLIDADO_DESEMPENIO_INDV_INTRODUCCION

Clave elemento a editar

Request Body schema: multipart/form-data
optional
archivoMembrete
required
string <binary>

archivo png para membrete de hoja pdf, debe ser de 850x1100px, solo no requerido cuando es CONSOLIDADO_DESEMPENIO_COLORES_TEXTO

textoPersonalizable
required
string

html simple de texto personalizado a usar en esa sección del pdf, requerido solo en algunos elementos que tienen personalizable el texto como CONSOLIDADO_DESEMPENIO_INDV_INTRODUCCION

required
object (JsonColores)

json usado en elemento CONSOLIDADO_DESEMPENIO_COLORES_TEXTO y solo es requerido en ese momento

Responses

Servidor de producción

https://clientex.talento.cloud/api/html/mapatalento/pdf/editarElementosPDF/{codModeloMapaTalento}/{idElemento}/json

Servidor de pruebas

https://clientex.talento-dev.cloud/api/html/mapatalento/pdf/editarElementosPDF/{codModeloMapaTalento}/{idElemento}/json

Response samples

Content type
application/json;charset=UTF-8

  • "message": "Los datos se almacenaron correctamente.",
  • "success": true
}
