Microservicio para gestión en talento cloud del módulo de Encuestas, pensado para ser consultado por chatbot ClaudIA.

Manejo de errores

Los errores habituales pueden incluir:

- `401 Unauthorized`: Token JWT inválido, expirado o ausente.

- `403 Forbidden`: El usuario autenticado no tiene la licencia necesaria para el módulo de Encuestas.

- `405 Method Not Allowed`: Se usó un verbo HTTP distinto de GET/HEAD/OPTIONS contra esta
ruta — todos los endpoints de este chatbot son de solo lectura.

- `500 Internal Server Error`: Error inesperado en el servidor.


Cuando sea posible, cada endpoint detallará sus códigos de error
específicos y estructura de respuesta en su propia descripción.

Encuestas

pendientes

Retorna las encuestas pendientes de responder del usuario autenticado (identificado por el token de sesión, nunca por parámetro). Solo lectura: no crea, modifica ni elimina información, y no admite ningún parámetro de query ni de path.

Criterio de "pendiente": una encuesta aparece en el listado cuando, para el usuario autenticado, existe una fila de población (fd_formulario_usuario) asociada a un proceso de encuesta (fd_proceso_encuesta) que está activo (estado=PUBLICADO y, si tiene fecha de vencimiento configurada, que aún no se haya cumplido) y que el usuario todavía no ha respondido (su estado en fd_formulario_usuario es distinto de REALIZADA y de VENCIDA).

Encuestas anónimas incluidas: a diferencia del listado no-chatbot equivalente (/encuestas/proceso/listarProcesosUsuario), este endpoint sí incluye los procesos marcados como anónimos — se identifican con el campo anonima=true por encuesta. No se expone el hash de acceso directo al formulario (ese hash funciona como token de acceso sin sesión), así que Claudia puede informar al usuario que la encuesta existe pero no puede enlazarlo directamente al formulario.

Información resumida, sin estructura completa: cada encuesta pendiente trae únicamente codigoProceso, nombreEncuesta, fechaLimite, cantidadPreguntas y anonima — nunca las preguntas, secciones, opciones de respuesta ni la población del proceso. cantidadPreguntas cuenta los campos reales de la encuesta, excluyendo los de tipo "título" (separadores visuales que no son preguntas que el usuario deba responder).

Sin pendientes no es un error: si el usuario no tiene ninguna encuesta pendiente, la respuesta sigue siendo 200 OK con tieneEncuestasPendientes=false, cantidadPendientes=0, encuestas=[] y un message explicativo ("No tienes encuestas pendientes por responder."). Cuando hay pendientes no se incluye message.
