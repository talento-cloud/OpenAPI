Microservicio para gestión en talento cloud del módulo de Beneficios, pensado para ser consultado por chatbot ClaudIA.

Manejo de errores

Los errores habituales pueden incluir:

- `401 Unauthorized`: Token JWT inválido, expirado o ausente.

- `403 Forbidden`: El usuario autenticado no tiene la licencia necesaria para el módulo de Beneficios.

- `405 Method Not Allowed`: Se usó un verbo HTTP distinto de GET/HEAD/OPTIONS contra esta
ruta — todos los endpoints de este chatbot son de solo lectura.

- `500 Internal Server Error`: Error inesperado en el servidor.


Cuando sea posible, cada endpoint detallará sus códigos de error
específicos y estructura de respuesta en su propia descripción.

Beneficios

saldoPuntos

Retorna el saldo de puntos de beneficios disponible para el usuario autenticado (identificado por el token de sesión, nunca por parámetro) en el año calendario actual. Solo lectura: no crea, modifica ni elimina información, y no admite ningún parámetro.

Disponibilidad del esquema de puntos: si el cliente no tiene habilitada la propiedad BNE_MANEJO_BENEFICIO_PUNTOS, el endpoint no consulta ningún saldo — responde data.disponible=false con un mensaje explicativo. Esto es distinto de un saldo en cero: un cliente sin el esquema habilitado nunca debe interpretarse como un usuario con 0 puntos.

Desglose por categoría: cuando el esquema de puntos sí está habilitado, la respuesta siempre trae data.puntos con las dos categorías (Beneficio y Reconocimiento), nunca un número suelto ni una categoría omitida. Cada elemento es {categoria, activo, saldoPuntos}: Beneficio siempre viene con activo=true (ya se validó que el cliente maneja puntos). Reconocimiento viene con activo=true y su propio saldoPuntos solo si el cliente tiene activa la propiedad BNE_RECONOCIMIENTOS_ACTIVO; si no la tiene, viene con activo=false y sin el campo saldoPuntos — nunca se consulta ni se muestra un saldo para una categoría inactiva, ni se suman los saldos de ambas categorías en un solo total. El nombre de la categoría viene traducido según el idioma del cliente/empresa (i18n).

El saldo de una categoría es bne_consolidado_transaciones_beneficios_usuario.saldo_puntos para el usuario, el año actual y esa categoría; si el usuario no tiene fila de transacción registrada para esa combinación (por ejemplo, aún no se le han asignado puntos ese año), el saldo se responde en 0, no como un error.
